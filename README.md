# CodeCrafters Coding Agent Challenge

This is my implementation of the [CC challenge](https://app.codecrafters.io/courses/claude-code/overview).
It is a coding agent that can read and edit files as well as run
commands on the shell. 

Needless to say, this should not actually be used. It might 
break your system, or worse. 

It is simply a study project to try to really understand how 
tools like [OpenCode](https://opencode.ai/) work under the hood.
